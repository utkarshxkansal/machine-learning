# Machine Learning Journey

A practical learning repository documenting my journey through Python for data science, data analysis, and machine learning.

I use this repository to organize my Jupyter notebooks, understand core concepts, practise implementations, and build projects as I progress.

## Learning roadmap

| Area | Topics |
|---|---|
| Python for ML | Python fundamentals, functions, modules |
| NumPy | Arrays, indexing, broadcasting, numerical operations |
| Pandas | Series, DataFrames, cleaning, grouping, analysis |
| Data visualization | Matplotlib, Seaborn |
| Machine learning | Regression, classification, model evaluation, regularization |
| Projects | End-to-end datasets and practical ML applications |

## How to explore

Open the topic folders and select a `.ipynb` notebook to view its code and outputs on GitHub. Notebooks can also be downloaded and run locally using Jupyter.
