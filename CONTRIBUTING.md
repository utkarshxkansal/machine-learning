# Contributing

Thanks for taking the time to improve this learning repository.

This repository is primarily a personal learning record, but constructive suggestions, corrections, and improvements are welcome.

## Ways to contribute

- Report an incorrect explanation, code issue, or broken dataset path.
- Suggest a clearer explanation or a useful exercise.
- Improve notebook readability and reproducibility.
- Suggest a topic or a small project.

## Before submitting a change

1. Keep changes focused on one topic.
2. Use descriptive file and folder names.
3. Add a short Markdown introduction to new notebooks describing the objective and concepts.
4. Use relative paths for datasets stored in this repository.
5. Avoid committing virtual environments, cache folders, credentials, or unrelated generated files.
6. Run the notebook from top to bottom when practical and make sure the cells execute as expected.

## Pull request workflow

1. Fork the repository.
2. Create a branch for your change.
3. Make and test your changes.
4. Open a pull request with a short explanation of what changed and why.

For small corrections, opening an issue first is also fine.
